# ابن حميدو — Seafood House

موقع عربي RTL متجاوب بهوية بصرية مستقلة عن مشروع كبابجي الغول.

## النشر على GitHub Pages
1. فك ضغط الملف.
2. ارفع الملفات الثلاثة (`index.html`, `style.css`, `script.js`) إلى جذر Repository جديد.
3. من Settings → Pages اختر Deploy from a branch.
4. اختر `main` و`/ (root)` ثم Save.

## التخصيص
- رقم الهاتف وواتساب: `01028080442` داخل `index.html` و`script.js`.
- الأصناف والأسعار: مصفوفة `menu` داخل `script.js`.
- الألوان والتصميم: أعلى `style.css`.

## ملاحظة مهمة
سلة الطلبات تعمل على الواجهة، وزر الإرسال يفتح واتساب برسالة طلب جاهزة. لا يوجد دفع إلكتروني أو نظام استقبال طلبات على سيرفر. الصور والخطوط خارجية وتحتاج إنترنت.
